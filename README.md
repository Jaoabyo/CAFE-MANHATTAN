# Manhattan Coffee House — Website Institucional

Website institucional de uma cafeteria fictícia, desenvolvido como projeto de portfólio para demonstrar habilidades em **HTML5** e **CSS3**. A página apresenta uma navegação simples por seções, identidade visual consistente e conteúdo essencial para um negócio local (apresentação, localização e horários).

## Visão geral
O site foi estruturado como uma landing page, priorizando clareza na comunicação, organização do layout e boa apresentação visual. O projeto também reforça boas práticas de front-end para páginas estáticas, como hierarquia de conteúdo, tipografia e separação de estilos por componentes/seções.

## Funcionalidades
- Navegação por âncoras (menu levando às seções)
- Seções institucionais: **Sobre**, **Contato/Endereço** e **Horário de Funcionamento**
- Mapa incorporado via **Google Maps**
- Efeito visual com imagens em parallax
- Layout adaptável para diferentes tamanhos de tela

## Tecnologias
- HTML5
- CSS3
- Google Fonts
- Google Maps Embed
